# Riftbound Versus showcase

The homepage feature and `/riftboundvs/` focus on the desktop web product. The portfolio itself adapts to narrow screens; it does not promote the mobile game experience.

## Media provenance

- `arena.png`: existing real game capture from the RiftboundVS repository, `docs/ux-audit/pr-246/10-desktop-game-overlay-after.png`. It shows a paused opponent decision and the action ledger. A fresh guest practice session stalled at the loading screen during capture, so this established product screenshot was reused.
- `cards.png`, `card-detail.png`, `deck-builder.png`: captured from the live desktop web app on September 13, 2026, in a guest session. The sample Ahri deck was auto-filled locally, not published.
- `product-tour.mp4` / `.gif`: a nine-second sequence of the three live screenshots above, three seconds per screen. This is a screen tour, not a continuous gameplay recording. The MP4 is approximately 210 KB; the optional GIF is approximately 315 KB. Video is user-initiated, muted, looping, and uses `preload="none"`.

Screenshots remain unretouched. The page credits the original game/artwork owners. Refresh these assets when the featured interfaces materially change.
