# Hexicon showcase assets

Actual Godot screen captures and production enemy portraits from Hexicon 0.2.6,
exported in `hexicon/art/paper-handoff/releases/0.2.6` (source commit
8a5ee828eb781ebf3b2ef4b4d2e9daeb6ab8f440). Screen captures are 390 × 844
fixture renders; portraits are 512 × 512. These are the assets referenced by
the Paper “Current release · 0.2.6” design page, not reconstructed mockups.
