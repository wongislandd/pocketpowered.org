# Riftbound Versus showcase

The homepage feature and `/riftboundvs/` focus on desktop gameplay: committing cards, contesting battlefields, responding to opponents, and following turn resolution. An interactive board walkthrough highlights battlefields, the hand, and the reaction chain/action ledger. Card browsing and deck building appear only as supporting links.
